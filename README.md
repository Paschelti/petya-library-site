# Petya Library site

Static GitHub Pages preparation for the Petya Library app.

## Pages

- `/` — app description
- `/privacy/` — Privacy Policy
- `/terms/` — Terms of Service

The public contact and effective date are set in the legal pages. Do not add OAuth credentials, access tokens, local configuration, or internal network addresses.

## Publication gate

This directory has been prepared and locally tested. Creating a public GitHub repository, pushing it, enabling GitHub Pages, and publishing the URLs are the authorized next steps.

Public policy for Petya Library.

1. What the application is

Petya Library is a private, self-hosted application operated by the account owner. It organizes TikTok data that the account owner chooses to make available through official TikTok authorization and APIs.

The application is not a public social network. It does not publish TikTok content, send TikTok messages, or modify the TikTok account.

2. Data processed

Depending on TikTok approval, API availability, and consent, the application may receive profile information and available video-related metadata, including references to liked or favorited content where TikTok makes that data available.

The application may organize available metadata into a searchable personal library and categorize it using locally hosted AI models. The exact data categories depend on TikTok and are not guaranteed by this policy.

3. Processing and storage

The application is designed to run on infrastructure controlled by the account owner. Processing, storage duration, backups, and access controls depend on that infrastructure and its configuration.

This policy does not promise a particular encryption, backup, deletion, retention, or availability mechanism unless separately implemented and documented.

4. Authorization and sharing

TikTok authorization is handled through official authorization flows. The account owner decides whether to authorize access and which approved permissions to grant.

The application is designed for private use and does not intentionally sell data or share it for advertising. Data may be processed by infrastructure and locally hosted models operated by or for the account owner.

5. Retention and deletion

Retention and deletion depend on the actual self-hosted deployment. The operator must document and implement applicable procedures before publishing this policy. No automatic deletion feature is claimed by this draft.

6. Security and changes

The operator should protect the deployment, OAuth credentials, access tokens, backups, and administrative interfaces. No security certification is claimed by this draft.

Questions and deletion requests should use the contact listed above. The policy must be updated before material changes in data sources, processing, hosting, sharing, or retention.

7. TikTok terms

Use of TikTok and TikTok data remains subject to TikTok’s applicable terms, policies, and developer requirements.
